# Fictional biology teaching notes
Project-authored synthetic teaching material. All experiment names, observations and numbers are invented. This is not scientific evidence or practical laboratory guidance.

# MICA observation
In the fictional MICA dataset, a cell-shaped drawing has twelve membrane markers. This statement describes the classroom drawing, not actual cell biology.

# TERN compartments
The fictional TERN drawing has two compartments labelled north and south. North contains the orange tokens; south contains the purple tokens.

# KESTREL change
In the fictional KESTREL exercise, a diagram changes from four loops to six loops. The teacher calls that change loop expansion.

# PEBBLE mass
The fictional PEBBLE record lists a mass of 7 mg. The units are milligrams, not grams.

# FINCH timing

# HERON comparison
In the fictional HERON handout, panel A has three arrows and panel B has eight arrows. Panel B therefore has five more arrows than panel A.

# WREN ordering
The fictional WREN teaching sequence is label, compare, record. The compare stage comes second.

# OTTER exclusion
The fictional OTTER dataset excludes row Q because its identifier is missing. The handout does not describe any other reason for excluding row Q.

# CLOVER ratio
The fictional CLOVER chart contains two red tokens for each blue token. The red-to-blue ratio in this drawing is 2:1.

# SABLE boundary
The fictional SABLE notes describe only one simulation session. They explicitly do not establish that its observations apply to real organisms or other sessions.
