# Course protocol: fictional teaching data
This is project-authored fictional course material for grounding evaluation, not an actual laboratory protocol. Names, values and procedures below are invented. Do not use them for real experiments.

# ORION
ORION is the course's fictional calibration label. The ORION label is written on the blue worksheet before any other step.

# VEGA
VEGA is the fictional sealing step. VEGA follows ORION and closes the violet vessel with a paper lid.

# LUMEN
The fictional LUMEN detector displays amber when a worksheet is readable. Its indicator is checked after VEGA.

# ASTER
The fictional ASTER control has no dye. ASTER is compared with the LUMEN indicator, not with the vessel colour.

# NOVA
The fictional NOVA wait lasts five minutes. NOVA starts after the ASTER comparison is recorded.

# TRACE
TRACE records the ORION label and the LUMEN indicator in the same log entry. The entry must contain both fields.

# RIVET
The fictional RIVET exercise provides seven samples. RIVET samples are counted before the SLATE allocation.

# SLATE
SLATE allocates three aliquots per RIVET sample. The worksheet calculation is 7 * 3. These are invented classroom quantities, not laboratory instructions.

# GATE
GATE completes only when the LUMEN indicator is amber and the ORION label is present in TRACE. A green indicator does not complete GATE.

# QUARANTINE
The fictional QUARANTINE rule pauses the course exercise if the LUMEN indicator is green. It resumes only after the instructor provides a replacement worksheet.
