# Grounded visual output contracts

Visuals are optional and do not replace the delivered text answer. Off, Auto
and explicit source/diagram/comparison/procedure/plot choices remain available.
The model proposes bounded data; application code renders it. No model-written
Python, Mermaid, HTML, SVG paths or external URLs are executed.

For recognised, complete source-stated structures, application code first
assembles and checks a request-bound catalogue. The model selects fact or
observation IDs and layout options; it does not recopy numbers, relationships,
procedure endpoints or comparison cells. Selected structures are checked again
against the immutable answer context before rendering. Manual and Auto modes
share this path. Unsupported formats retain the general constrained proposal
path; a partial catalogue never silently discards scope or uncertainty.
This compiler currently recognises direct observation statements and explicit
relationships/order, not arbitrary prose or all table formats.
Admission requires complete literal claim/source equality, including numeric
signs and conditions. Document ownership remains part of entity and trajectory
identity: matching labels alone never establish one cross-document pathway or
time series. Until a separately checked shared identity exists, entities remain
separate and a cross-document trajectory is declined.
General v2 numeric proposals must also bind a complete literal retained source
clause; matching group/value tokens alone cannot drop conditions or change a
sign. Uncertainty uses the same retained-clause check. Factual containment shares
the graph's document-ownership validation; neutral presentation groups do not
assert compartment membership.

## Source inspection

Explicit Ask preparation uses local figure descriptions v2, with the actual
question, native caption context and existing OCR hints. A question shares a
two-provider-call budget (including repair) and a 300-second deadline. Thinking
remains opt-in. No provider/model switching is implicit.

Native table-row geometry can select a complete row together with its header
context. Crops come from the original upright render before downscaling. Model
bounding boxes do not become trusted highlights. If precise ownership is
unavailable, processing visibly uses the owned whole figure/manual crop.

Derived units keep panel IDs, table row/header IDs, null/missing cells, raw
responses, question/source identity and unresolved caption/pixel disagreements.
Caption subjects are not automatically classified as organisms. Existing v1
descriptions/config identities remain readable.

Source views may reuse inspection geometry only from immutable revisions
already selected into the answer's evidence. A newer active interpretation is
not attached retrospectively. A highlight identifies material to inspect; it
does not independently verify a claim. VLM/OCR numbers remain uncertified.

## Diagrams

V2 diagrams add LR/TD orientation, entity/process/condition shapes, groups,
qualifiers and condition records. Relationships bind complete retained claims
to exact source spans. Cyclic layout never manufactures a return edge. Factual
containment needs its own part-of support; presentation groups are explicitly
neutral. Inhibition has a blunt end, association is unheaded, and interpreted
connections retain dashed strokes. Nodes retain keyboard-accessible citations.
V1 diagram inputs remain accepted through the legacy contract.

## Scientific plots

V2 plots accept native source observations only. The same entity, population,
condition, quantity and source scope must be retained before a line can join
observations. Missing values stay null. Unknown/omitted prefix or suffix scope
is rejected, not guessed. Strict direct-statement bindings currently mean that
some prose and noncanonical table formats will be declined; a source figure can
still be displayed without regenerating its numerical data.

Supported views are grouped scalar plots, unjoined scatter, native matrix
heatmaps, source-stated bins and individual source observations. Repeated-group
samples receive separate positions. Matrices retain row/column ownership and
distinguish missing cells from zero. No fits, smoothing, synthetic samples,
aggregates, unit conversions or simulations are introduced.

Uncertainty must preserve its source-defined SD, SEM, confidence interval or
stated interval, with the center's complete scope. Mean +/- supplied SD/SEM is
derived drawing geometry, not a newly observed endpoint or an inferred CI.
Original decimal strings, units, definitions and per-observation sources remain
in the data table and export. Scalar v2 charts use trusted deterministic SVG;
legacy v1 Recharts rendering is retained.

## Verification status

Automated schema/grounding/render tests do not establish real model accuracy.
The original frozen 12-case bank is unchanged. The separate 30-case extension
retains 20 positive cases and 10 live safety controls. Its gate requires at least
3/4 faithful/readable outputs in each positive kind and manual safe-assertion
review of all ten controls. Errors, omissions, deferred and unattempted cases
remain in the denominator. Authored renderer fixtures and real PDF cases must
be reported separately.

The production evaluation runner uses the actual Ask preparation/index/answer
path, captures its real private trace, pins code/config/model digest, and rejects
missing hybrid/reranker/NLI/model stages. Resource deferral is not a pass. Current
release status remains pending full regression and manually reviewed live runs.

New anatomical illustrations, cell/leaf component libraries, generated artwork,
internet search, fine-tuning and application-wide frontend redesign are deferred.
